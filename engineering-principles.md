# Engineering Principles

**Purpose:** Define the non-negotiable engineering standards that guide all SEC project work.

**Intended audience:** All SEC members, coordinators, reviewers, and contributors.

**Last updated:** 2026-09-30  
**Owner:** President

## Principles

1. Documentation first.
2. Every feature begins with a GitHub Issue.
3. Every issue has acceptance criteria.
4. Every change requires a pull request.
5. Every pull request requires peer review before merge.
6. The main branch is always deployable.
7. Security is everyone's responsibility.
8. Learning over ego.
9. Research before implementation.
10. Decisions are documented.
